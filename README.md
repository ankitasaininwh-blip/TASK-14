# TASK-14
JavaScript - Loops

Objective

Create a JavaScript program using loops and conditional statements to perform different operations on a given number.

Operations Performed

- Find the sum of first "n" numbers.
- Print the multiplication table of "n".
- Check whether the number is prime.
- Find all factors of the number.
- Find the sum of all digits.
- Check whether the number is an Armstrong number.
- Display all results using "console.log()".

Example Input

153

Example Output

Is it a prime number? No
Factors: 1, 3, 9, 17, 51, 153
Sum of digits: 9
Is it an Armstrong number? Yes
